# 北理工重开模拟器

基于《人生重开模拟器》改编的北京理工大学特供版文字游戏，模拟本科四年。
仅借鉴玩法结构，**文案与数据全部原创**。

## 运行环境

- Python 3.12（本机实测 3.12.10）
- pygame 2.6.1（唯一第三方依赖）
- Windows

安装依赖（本机已装好，可跳过）：

    pip install pygame

## 运行

仓库中的代码是**游戏原型**，位于 `prototype/`：

    cd prototype
    python main.py

## 操作

| 阶段 | 操作 |
| --- | --- |
| 抽天赋 | 鼠标点击 5 个天赋中的 3 个，点「确定」 |
| 分配属性 | 用每行的 `-` / `+` 把 20 点分给 4 项属性（每项上限 10），点「开始大学四年」 |
| 游戏中 | 点「继续」/ 按空格或回车推进一个月；点「自动」开启自动推进；点速度按钮切换 1 / 2 / 4 秒 |
| 结局 | 点「再来一次」重开 |

## 玩法规则

- 时间轴：第 1 回合 = 大一 9 月，第 48 回合 = 大四 8 月（毕业）
- 属性：智力 / 体质 / 颜值 / 家境，开局 20 点自由分配
- 书院：系统随机分配（睿信 / 求是 / 明德 / 特立），个别天赋可指定书院
- 专业：大二开学（第 13 回合）由系统在本书院可选范围内随机分配
- 事件：每月 1 条。**通用事件可重复出现，特殊事件每局只出现一次**
- 天赋：随机抽 5 个选 3 个，效果是「开局属性加成」和「提高某类事件的抽取概率」
- 结局：第 48 回合按 `Σ(属性值×权重) + Σ(经历标签次数×权重)` 给每个结局算分，取最高分

## 改文案

所有文案都在 `prototype/data/*.json` 里，**改文案不用动代码**。

事件字段说明：

| 字段 | 含义 |
| --- | --- |
| `text` | 事件文案 |
| `type` | `通用`（可重复）或 `特殊`（每局只出现一次） |
| `stage` | 时段：`常规` / `军训` / `期末` / `寒暑假` / `实习` |
| `need` | 属性下限，例如 `{"智力": 6}`；`{}` 表示不限 |
| `shuyuan` | 限定书院，空数组表示不限 |
| `major` | 限定专业，空数组表示不限 |
| `effects` | 属性变化，例如 `{"智力": 1, "体质": -1}` |
| `tags` | 结局标签 |
