# 北理工重开模拟器

基于《人生重开模拟器》改编的北京理工大学特供版文字游戏，模拟本科四年。
仅借鉴玩法结构，**文案与数据全部原创**。

## 运行环境

- Python 3.12（本机实测 3.12.10）
- pygame 2.6.1（唯一第三方依赖）
- Windows

安装依赖（本机已装好，可跳过）：

    pip install pygame

## 运行

在**仓库根目录**执行：

    python main.py

（`prototype/` 保留的是早期原型，不是正式版）

## 操作

| 阶段 | 操作 |
| --- | --- |
| 抽天赋 | 从随机抽出的 5 个天赋里最多点选 2 个 |
| 分配属性 | 用每行的 `-` / `+` 把 20 点分给 4 项属性（每项上限 10），点「开始大学四年」 |
| 游戏中 | 点「继续」/ 按空格或回车推进一个月；点「自动」开启自动推进；点速度按钮切换 1 / 2 / 4 秒 |
| 结局 | 点「回顾本局」/「返回首页」/「再来一局」 |

## 玩法规则

- 时间轴：第 1 回合 = 大一 9 月，第 48 回合 = 大四 8 月（毕业）
- 属性：智力 / 体质 / 颜值 / 家境，开局 20 点自由分配
- 书院：系统随机分配（睿信 / 求是 / 明德 / 特立），个别天赋可指定书院
- 专业：大二开学（第 13 回合）由系统在本书院可选范围内随机分配
- 事件：每月 1 条。**通用事件可重复出现，特殊事件每局只出现一次**
- 天赋：随机抽 5 个、最多选 2 个，效果是「开局属性加成」「提高某类事件的抽取概率」「指定书院」「强制某类事件」等
- 结局：第 48 回合按「**硬门槛 + 加权竞争**」判定，共 11 条（升学 5 / 就业 4 / 学业 1 / 兜底 1），升学类另按能力分定院校；详见 `docs/ending.md`

## 改文案

所有文案都在 `data/*.json` 里，**改文案不用动代码**。

事件字段说明：

| 字段 | 含义 |
| --- | --- |
| `text` | 事件文案 |
| `type` | `基础`（可重复）或 `特殊`（每局只出现一次） |
| `stage` | 时段列表：`常规` / `军训` / `期末` / `寒假` / `暑假` / `实习` / `答辩` |
| `need` / `need_max` | 属性下限 / 属性上限，例如 `{"智力": 6}` |
| `shuyuan` / `major` | 限定书院 / 专业，空数组表示不限 |
| `flags_need` / `flags_forbid` | 需要/禁止的状态（如 `恋爱中`、`组织`） |
| `effects` | 属性变化，例如 `{"智力": 1.5, "体质": -0.5}` |
| `tags` | 结局判定门槛与竞争权重用（也是天赋加权的匹配标签） |
| `check` | 判定：二选一 / 多档 / 只出分，详见 `docs/event.md` |
