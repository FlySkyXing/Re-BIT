# 01 可行性分析

> 状态：**已编写，待人类确认**（准则八：逐项由人类确认后再进入下一项）

## 1. 项目背景与目标

- **课程**：软件工程小学期作业，需交付源工程、应用程序、程序演示视频、汇报 PPT、《项目文档》
- **题目**：北理工重开模拟器 —— 基于《人生重开模拟器》改编的北京理工大学特供版文字游戏
- **目标**：以文字事件驱动的方式模拟北京理工大学本科生四年经历，支持反复"重开"

## 2. 技术可行性

| 考察点 | 结论 |
| --- | --- |
| 开发语言 | Python 3.12（本机 3.12.10 已安装），语法简单，适合课程作业 |
| 图形界面 | pygame 2.6.1（本机已安装）；文字游戏只需文本渲染与点击响应，性能压力极低 |
| 中文显示 | 调用系统字体（微软雅黑）即可正常显示中文 |
| 数据存储 | 四份 JSON 文案文件（天赋 / 事件 / 结局 / 成就），改文案不用改代码 |
| 关键技术难点 | 无。事件筛选、结局判定均为简单遍历与随机抽取 |
| 验证情况 | 已有可运行原型（`prototype/`），48 回合流程、自动推进、结局判定均已跑通 |

**结论：技术可行。**

## 3. 经济可行性

- 开发语言、图形库、编辑器均为免费开源工具，无采购与授权成本。
- **结论：经济可行。**

- 单人操作，三种推进方式：鼠标点「继续」、键盘空格/回车、自动推进（1 / 2 / 4 秒可切换）。
- 无需安装配置，在仓库根目录执行 `python main.py` 即可（原型保留在 `prototype/`）。
- **结论：操作可行。**
