# 02 游戏设计

> 状态：**已编写，人类已确认；按新增要求补充成就系统与回顾，待确认**（准则八）
> 本文件只写玩法规则，不含代码；实现细节（算法、字段）见 `04-程序设计.md`。

## 1. 游戏概述

| 项 | 内容 |
| --- | --- |
| 名称 | 北理工重开模拟器 |
| 原型 | 《人生重开模拟器》—— 只借鉴玩法结构，**文案与数据全部原创**，不使用其数据文件 |
| 类型 | 文字模拟 / 养成，单机 |
| 主题 | 北京理工大学本科四年 |
| 单局时长 | 约 5–10 分钟（48 回合） |
| 重开机制 | 结局页可直接「再来一局」；书院、专业、天赋、事件随机，同一套路可玩出不同结局 |
| 长期目标 | 通过成就系统与回顾功能，鼓励反复重开 |

**一句话玩法**：抽天赋 → 分配属性 → 每月触发一条事件 → 四年后按属性与经历判定结局。

## 2. 核心玩法循环

1. **首页**：开始游戏 / 成就 / 回顾 / 退出游戏
2. **开局页**：系统随机分配书院 → 从天赋池随机抽 5 个、**玩家最多选 2 个（可少选或不选）** → 玩家把 20 点分给 4 项属性（天赋与属性在同一页）
3. **每月一个回合**：按当前时段与条件筛选事件 → 随机触发 1 条 → 显示事件文案与属性变化
4. **第 13 回合（大二 9 月）**：系统在本书院可选范围内随机分配专业
5. **第 48 回合（大四 8 月）**：按硬门槛与实际经历给 11 个结局判定（详见本文件 §7）
6. **结局页**：三个按钮 —— 回顾本局 / 返回首页 / 再来一局

## 3. 属性系统

| 属性 | 分配时 | 作用 |
| --- | --- | --- |
| 智力 | 整数点，每项上限 10 | 学习、科研、竞赛类事件的判定 |
| 体质 | 整数点，每项上限 10 | 体测、军训、作息类事件的判定 |
| 颜值 | 整数点，每项上限 10 | 社交、社团类事件的判定 |
| 家境 | 整数点，每项上限 10 | 经济类事件的判定 |

- 开局 **20 点自由分配**，每项分配上限 10，**可以分不完直接开始**（人类裁定）
- **属性不封顶**：事件与天赋叠加后允许超出 0–10（人类裁定）
- **属性值允许非整数**：事件与天赋可以加减小数，**最小单位 0.1**（人类裁定）；分配时仍按整数点
- 属性变化**只由事件与天赋驱动**，没有其他来源

- **专业由系统在本书院可选范围内随机分配**，玩家不能自选

| 等级 | 名称 | 颜色 | 概率 | 属性加成 |
| --- | --- | --- | --- | --- |
| 蓝 | 稀有 | `#3A76D0` | 75% | +1 |
| 紫 | 史诗 | `#8052C6` | 20% | +2 |
| 金 | 传说 | `#C69418` | 5% | +4 |

- 效果分两类：
  1. **开局属性加成**（4 属性 × 3 等级 = **12 个属性天赋**，数值 +1 / +2 / +4）

## 6. 事件系统

- **每回合 1 条**，事件池 **≥100 条**，原创文案
- 事件分四类（人类裁定）：

| 类别 | 说明 |
| --- | --- |
| **基础事件** | 校园日常，有好有坏；含**无属性影响**的纯叙事、**保底事件**（属性变化 0.1~0.3、低权重常驻候选池）、**有前提条件**的事件 |
| **特殊事件** | 有**概率**（`chance`）与**条件**（天赋 / 属性 / 前置事件）限制，通常本局只出现一次 |
| **判定事件** | 触发后按属性掷判定，成功 / 失败得到不同文案与效果 |
| **特殊时段事件** | 军训 / 期末 / 寒假 / 暑假 / 实习 / 答辩各有**独立候选库**，与日常事件不混用 |

- **状态标志（flags）**：与结局标签分开的状态集合（如 `恋爱中`、`学生组织`）。事件用 `flags_need`（必须已具备）/ `flags_forbid`（必须不具备）作前提条件，用 `flags_set` / `flags_clear` 增删状态 —— 以此避免"未恋爱就分手""恋爱后还表白"这类矛盾
- **判定**：事件内写 `base` 与属性系数，**成功率 = base + Σ(属性值 × 系数)**，夹在 5%~95%；例如表白成功率由**颜值与家境**决定，竞赛结果由**智力**决定
- **判定的三种形式**：二选一（`success` / `fail`）、多档（`levels`，按得分取档，如竞赛奖项）、只出分（`score`，如四六级）—— 详见本文件 §6.4
- 每条事件包含：文案、类型、时段、触发条件、属性变化、结局标签、状态变化
- **寒假与暑假是两个独立时段**；事件用 stage **列表**声明适用时段，命中其一即可触发 —— 因此两者**可共用同一事件池**（如 ["寒假", "暑假"]），也可各自专属；**文案必须写清属于哪个假期，不得混淆**
- 属性变化幅度：**2 以内**，大部分为**非整数小数值**（最小单位 0.1），重大事件幅度更大（人类裁定）
- 事件总数 **191 条**（基础 101 / 特殊 90；常规 106、特殊时段 85），清单见 `docs/list/event-list.md`
- **恋爱线**：主动表白 4 条（异性 2 条 + 同性 2 条，同性需「彩虹之下」）；被表白 4 条（异性 / 同性，**触发率由颜值决定**，答应与否各 50%）；在一起后用 `恋爱中` 状态驱动约会 / 争吵 / 分手
- **入党线**：递交入党申请书 → 入党积极分子 → 正式党员，**三步**用状态依次卡顺序；转为正式党员后带 `党员` 标签，进入编制 / 援建乡村的竞争权重更高
- 每个时段都有**保底事件**（`weight` 0.2），所以每月必定抽到事件；保底文案形如"这段时间过得平平淡淡，没什么可记的。"
- 详细设计见本节 §6.1 ~ §6.8

> 对应 本文件 §6。数据实现见 `data/events.json`。
> 状态：**已实现**：事件池 **191 条**（基础 101 / 特殊 90），覆盖常规与全部特殊时段。

### 6.1 事件分类

| 类别 | 说明 | 触发 |
| --- | --- | --- |
| **基础事件** | 校园日常，有好有坏；含少量**无属性影响**的纯叙事、少量**保底事件**、少量**有前提条件**的事件 | 按权重随机 |
| **特殊事件** | 有**概率**与**条件**（天赋 / 属性 / 前置事件）限制，通常本局只出现一次 | `chance` + 条件 |
| **判定事件** | 触发后按属性与天赋**掷判定**，成功 / 失败得到不同文案与效果 | `check` |
| **特殊时段事件** | 军训 / 期末 / 寒假 / 暑假 / 实习 / 答辩各自**独立的候选库** | 时段匹配 |

### 6.2 字段说明（`data/events.json`）

**必填**

| 字段 | 含义 |
| --- | --- |
| `text` | 事件文案；支持三个占位符：`{score}`（判定分数）、`{shuyuan}`（玩家所属书院，如「睿信科协」）、`{org}`（玩家所属学生组织，如「校科协」） |
| `type` | `基础` 或 `特殊`；`特殊` 每局只出现一次 |
| `stage` | **时段列表**，命中其一即可触发：`常规` / `军训` / `期末` / `寒假` / `暑假` / `实习` / `答辩` |
| `effects` | 属性变化，0.1 粒度；`{}` 表示无属性影响 |
| `tags` | 结局判定门槛与竞争权重用；也作天赋 `boost` / `force` 的匹配标签 |

**选填（省略即取默认值）**

| 字段 | 默认 | 含义 |
| --- | --- | --- |
| `need` | `{}` | 属性下限，例如 `{"智力": 6}` |
| `shuyuan` | `[]` | 限定书院 |
| `major` | `[]` | 限定专业 |
| `flags_need` | `[]` | **必须已具备**的状态（如 `["恋爱中"]`） |
| `round` | `0` | **固定回合**：指定后该事件只在第 N 回合可触发（`0` 表示不限）；是否抽中仍按权重与其他候选竞争（如第 13 / 25 回合的组织线） |
| `rewind` | 无 | 标记该事件是天赋「败者食尘！」的**回溯提示**：配合 `chance: 0` 不参与随机抽取，只由回溯机制显式触发（文案同样写在数据里） |
| `flags_forbid` | `[]` | **必须不具备**的状态（防止"恋爱后还表白"） |
| `flags_set` | `[]` | 事件后**获得**的状态 |
| `flags_clear` | `[]` | 事件后**移除**的状态（如分手解除「恋爱中」） |
| `chance` | `100` | 触发概率（百分比），用于特殊事件 |
| `chance_attr` | 无 | 概率**随属性变化**：`{base, attrs, max}`，即 `概率 = base + Σ(属性值 × 系数)`，上限 `max`（如被表白事件：颜值越高越容易被表白） |
| `weight` | `1` | 抽取权重；**保底事件用低权重（0.2）** |
| `check` | 无 | 判定配置，见下 |
| `need_max` | `{}` | 属性**上限**条件，例如 `{"家境": 3}` 表示家境小于 3 才触发 |
| `rank_bonus` | `0` | 本学期综测加分（期末复习 +5 / 摆烂 −8、竞赛获奖 +6~+18） |
| `visit` | 无 | 记录旅游到的省级行政区，用于「走遍全国」成就（跨局累计） |
| `score_field` | 无 | 把判定分数写入玩家字段（如 `cet6`） |
| `set_org` | 无 | 记录加入的学生组织名（写入玩家 `org`）；同样支持 `{shuyuan}` 占位符 |

### 6.3 状态标志（flags）

- `flags` 是玩家身上的**状态集合**（如 `恋爱中`、`学生组织`），与 `tags`（结局判定门槛与竞争权重用）**完全分开**，互不影响
- 状态由事件通过 `flags_set` 获得、`flags_clear` 移除
- 前提条件用 `flags_need`（必须已具备）与 `flags_forbid`（必须不具备）表达
- **典型用法**：表白成功 → `flags_set: ["恋爱中"]`；约会 / 争吵 → `flags_need: ["恋爱中"]`；分手 → `flags_need: ["恋爱中"]` + `flags_clear: ["恋爱中"]`；表白 → `flags_forbid: ["恋爱中"]`；语言考试（雅思 / 托福）→ `flags_forbid: ["语言考试"]`（两考互斥、各只有一次机会），达标分支 `flags_set: ["语言考试", "语言成绩达标"]`（出国留学的硬门槛）；同性在一起 → 成功分支 `flags_set: ["恋爱中", "同性恋爱"]`；表白被拒 → 失败分支 `flags_set: ["表白被拒"]`；**入党三步**用 `flags_need` 依次卡顺序（`入党申请` → `积极分子` → `正式党员`）；**组织线**用 `round` 卡在固定回合、按权重概率触发（第 13 回合 `组织` → `组织部长`，第 25 回合 `组织部长` → `组织主席`）；**回溯提示**由天赋「败者食尘！」限定（`flags_need: ["回溯"]` + `chance: 0`），只由回溯机制显式触发

### 6.4 判定（`check`）

    "check": {
      "base": 20,                          // 基础成功率（百分比）
      "attrs": {"颜值": 5, "家境": 2},      // 属性系数
      "success": {"text": "...", "effects": {...}, "flags_set": [...]},
      "fail":    {"text": "...", "effects": {...}}
    }

**三种判定：**

| 形式 | 用法 |
| --- | --- |
| `{base, attrs, success, fail}` | **二选一**：成功率 = base + Σ(属性值 × 系数)，夹在 5% ~ 95%；掷 1~100 决定成功 / 失败（如表白） |
| `{base, attrs, roll, levels}` | **多档**：得分 = base + Σ(属性值 × 系数) + random(0, roll)，取 `min` 不超过得分的最高档（如竞赛奖项） |
| `{score}` | **只出分**：`score = {base, attrs, roll, max}`，把分数（**取整为整数**）写进文案的 `{score}` 占位并记录到 `score_field`（如四六级） |

> 天赋的 `check_bonus` 会按事件 `tags` 命中加成：带「表白」标签的判定在 `花言巧语` 下 +25。

- 天赋可以通过 `boost` 影响**哪些事件出现**，通过属性加成间接影响判定成功率
- 判定结果决定**显示哪段文案**与**应用哪组效果**；成功分支还可以设置状态

### 6.5 保底事件

- 属性变化仅 **0.1 ~ 0.3**，`weight` 设为 **0.2**（常驻候选池、低权重）
- 作用：当其他事件因条件不满足而变少时，仍有事件可触发，避免出现"这个月没什么特别的事"

### 6.6 特殊时段事件库

| 时段 | 库内事件特征 |
| --- | --- |
| 军训 | 大一 9 月专属，体质与集体活动 |
| 期末 | 每年 1、6 月（大四 6 月除外），考试与成绩判定 |
| 寒假 / 暑假 | 各自专属 + 假期通用；见 `docs/02` 的时段表 |
| 实习 | 大四 3–5 月，职场与通勤 |
| 答辩 | 大四 6 月，毕业论文 |

> 各时段事件与日常事件**互不混用**：筛选时先按时段过滤，再按条件过滤。

### 6.7 抽取流程

1. 按时段过滤
2. 天赋 `force` 规则命中时，先把候选收窄为指定标签的事件
3. 按条件过滤：属性下限、书院、专业、`flags_need` / `flags_forbid`
4. 排除本局已出现过的 `特殊` 事件
5. 候选筛选阶段顺带掷 `chance`（默认 100），未通过的事件**不进候选池**
6. 按 `weight`（再乘天赋 `boost` 倍率）加权随机抽 1 条
7. 若事件带 `check`，掷判定决定文案与效果
8. 应用 `effects`，记录 `tags`，更新 `flags`

> 每个时段都有 **`weight` 0.2 的保底事件**，因此候选池不会为空、每月必定抽到事件（实测 4800+ 回合中"无事件回合"为 0）。
> 另外两类**不按常态参与抽取**的事件：带 `round` 的事件只在指定回合进入候选池；带 `rewind` 的事件 `chance` 为 0、永不进入候选池，只在天赋「败者食尘！」触发回溯时由代码显式取用。

## 7. 结局系统

- 结局池 **11 条**，分四类：**升学 5**（保研外校、保研本校、考研外校、考研本校、出国留学）、**就业 4**（进入大厂、创业、进入编制、援建乡村）、**学业 1**（延毕）、**兜底 1**（待业）
- 判定时机：第 48 回合
- 判定流程（**硬门槛 + 加权竞争**，人类裁定）：
  1. **延毕优先**：智力不达标直接延毕
  2. **硬门槛过滤**：不满足门槛的结局直接出局（如出国留学要求家境 > 7 **且考出语言成绩**）
  3. **升学类内部竞争**：按竞争权重抽一个
  4. **升学胜者与就业类竞争**：再按竞争权重抽一个
  5. **待业兜底**：一条都不剩时命中待业
- **保研看平均综测排名**：保研本校要求平均排名 ≤ **40%**、保研外校 ≤ **5%**，且保外校的院校**仅限高于北理层级**的 8 所
- 竞争权重 = `weight × Σ(√因子值 × 因子权重) × 随机系数` —— **边际效用**（因子取平方根）与**随机权重**（人类裁定）；因子指某项属性值或某个标签的出现次数
- 升学院校由能力分决定：`智力 × 10 + 家境 × 2`，取不低于该分的最高档
- 本章给出结局系统的完整设计（§7.1 ~ §7.8）；清单见 `docs/list/ending-list.md`

> 数据在 `data/endings.json`，可读清单见 `docs/list/ending-list.md`，判定代码在 `game/endings.py`。
> 判定时机：**第 48 回合（大四 8 月）结束时一次性判定**，判定结果写入 `save/records.json`。

### 7.1 概览

结局共 **11 条**，分四类：

| 类别 | 条数 | 结局 | 判定方式 |
| --- | --- | --- | --- |
| 升学 | 5 | 保研外校、保研本校、考研外校、考研本校、出国留学 | 内部先竞争出一个，再与就业类竞争 |
| 就业 | 4 | 进入大厂、创业、进入编制、援建乡村 | 与升学胜者竞争 |
| 学业 | 1 | 延毕 | 学业不达标时**优先**命中，不参与竞争 |
| 兜底 | 1 | 待业 | 所有结局都不满足门槛时命中 |

**判定五步**（`game/endings.py` 的 `judge_ending`）：

1. **延毕优先**：智力不达标（`need_max` 命中）→ 直接延毕
2. **硬门槛过滤**：逐条检查 `need` / `need_max` / `rank_max`，不满足的结局直接出局
3. **升学类内部竞争**：剩下的升学结局按「竞争权重」抽一个
4. **升学胜者与就业类竞争**：把第 3 步的胜者与所有满足门槛的就业结局放一起，再按竞争权重抽一个
5. **待业兜底**：第 2 步后一条都不剩时，命中待业

### 7.2 平均综测排名

保研类结局看的是**整四年的平均综测排名**，不是最后一次排名。

- 综测共 6 次：第 **5 / 10 / 17 / 22 / 29 / 34** 回合
- 每次综测先算得分：`综测得分 = 智力 × 10 + 本学期综测加分`（加分来自竞赛与事件的 `rank_bonus`）
- 得分换算成百分位：`百分位 = 100 − 100 × (得分 − 28) / 54`，夹在 1 ~ 100
- **平均综测排名 = 6 次百分位的均值**，越小越好

**为什么重校准公式**：旧公式把百分位压在 34% ~ 89%（均值 66%），「≤5%」在 1000 局里出现 **0 次**，「≤40%」只有 2.3% —— 保研的两个门槛都不可达。重校准后实测：**≤5% 约 5%、≤40% 约 43%**，与目标占比匹配。

### 7.4 竞争与随机权重

满足门槛之后，不是「得分最高者胜」，而是**按竞争权重抽签**：

```
影响因子得分 = Σ √(属性值或标签次数) × 权重        ← 边际效用：数值越大，单点收益越小
竞争权重     = weight × 影响因子得分 × random(0.7, 1.3)   ← 随机权重
```

- **边际效用**：因子贡献取平方根，避免「某一项刷高就锁死结局」。例如智力从 9 涨到 16，贡献只从 3.0 涨到 4.0
- **随机权重**：每个结局每次判定乘一个 0.7 ~ 1.3 的随机系数，让同一份经历也有不同走向
- **竞争权重下限 0.01**：援建乡村的家境权重为负，可能算成负数，取 0.01 防止抽签参数非法
- `weight` 是**层级/类别权重**，按目标分布校准（2026-09-16 第 7 项 300 局复测后重新标定）：升学类里保研本校最高（6.2），保研外校 3.5、出国留学 2.2、考研本校 1.9、考研外校 0.7；就业类因门槛宽松而整体压低（进入大厂 0.26、进入编制 0.5、创业 0.62），援建乡村因门槛较窄（41.3%）取 2.4
- **入党加成**：转为正式党员的玩家带 `党员` 标签，`进入编制` 与 `援建乡村` 的影响因子各加 `党员 × 3` —— 入党后更容易走向体制内或援建

#### 已知偏差：待业永远打不到

## 8. 成就系统

- 成就**跨局累计**，达成后永久保留
- 达成条件分七类（人类裁定）：
  1. **结局**：拿到某个指定结局（`value` 可为结局名或结局名列表）
  2. **事件**：经历过某条指定事件或判定结果文案
  3. **属性**：某属性达到指定数值
  4. **排名**：综测名次在指定名次以内
  5. **数值**：玩家字段达到指定值（如六级分数）
  6. **全局**：跨局累计（如走遍全国的省份数）
  7. **状态**：玩家身上的状态全部具备（如「同性恋爱」+「女」判定同性在一起）
- 另有**开局**类成就（开始一局游戏即达成）
- 当前共 **19 条**，清单见 `docs/list/achievement-list.md`

### 8.1 判定类型（八类）

| 类型 | 判定依据 | 例子 |
| --- | --- | --- |
| `结局` | 本局结局名命中（`value` 可为名字或名字列表） | 保研上岸（保研本校 / 保研外校） |
| `事件` | 本回合显示的事件文案或判定结果文案命中 | 军训标兵、吃一堑 |
| `属性` | 某属性达到指定值 | 学霸（智力 ≥ 9） |
| `排名` | 综测名次进入指定名次以内 | Rank1（名次 ≤ 1） |
| `数值` | 玩家身上的数值字段达到指定值 | 歪果仁（`cet6` ≥ 600） |
| `全局` | 跨局累计项达到指定数量（读存档） | 走遍全国（`provinces` ≥ 33） |
| `状态` | 玩家身上的状态**全部具备** | ！？拉拉！？（`同性恋爱` + `女`）、光荣入党（`正式党员`） |
| `开局` | 开始一局游戏即达成 | 北理新生 |

### 8.2 跨局累计机制

- 成就进度写在 `save/records.json` 的 `achievements` 列表里，**跨次运行保留**；同一成就只记录一次
- 每回合事件结算后检查一次（覆盖 `事件` / `属性` / `排名` / `数值` / `状态` 类），结局判定后再检查一次（覆盖 `结局` 类）
- `全局` 类读同一份存档里的累计项（如 `provinces` 省份数），因此**可能在多局之后才达成**

- 达成时游戏界面左下角弹出一个 3 秒的提示条
- 首页「成就」页可查看全部成就与达成状态（已达成高亮、未达成灰色）

## 9. 回顾功能

- **回顾页**：列出**最近 5 局**（每局记录书院、专业、性别、结局与所选天赋），可查看该局每月的文本与结局
