# 结局系统设计

> 数据在 `data/endings.json`，可读清单见 `docs/ending-list.md`，判定代码在 `game/endings.py`。
> 判定时机：**第 48 回合（大四 8 月）结束时一次性判定**，判定结果写入 `save/records.json`。

## 1. 概览

结局共 **11 条**，分四类：

| 类别 | 条数 | 结局 | 判定方式 |
| --- | --- | --- | --- |
| 升学 | 5 | 保研外校、保研本校、考研外校、考研本校、出国留学 | 内部先竞争出一个，再与就业类竞争 |
| 就业 | 4 | 进入大厂、创业、进入编制、援建乡村 | 与升学胜者竞争 |
| 学业 | 1 | 延毕 | 学业不达标时**优先**命中，不参与竞争 |
| 兜底 | 1 | 待业 | 所有结局都不满足门槛时命中 |

**判定五步**（`game/endings.py` 的 `judge_ending`）：

1. **延毕优先**：智力不达标（`need_max` 命中）→ 直接延毕
2. **硬门槛过滤**：逐条检查 `need` / `need_max` / `rank_max`，不满足的结局直接出局
3. **升学类内部竞争**：剩下的升学结局按「竞争权重」抽一个
4. **升学胜者与就业类竞争**：把第 3 步的胜者与所有满足门槛的就业结局放一起，再按竞争权重抽一个
5. **待业兜底**：第 2 步后一条都不剩时，命中待业

## 2. 平均综测排名

保研类结局看的是**整四年的平均综测排名**，不是最后一次排名。

- 综测共 6 次：第 **5 / 10 / 17 / 22 / 29 / 34** 回合
- 每次综测先算得分：`综测得分 = 智力 × 10 + 本学期综测加分`（加分来自竞赛与事件的 `rank_bonus`）
- 得分换算成百分位：`百分位 = 100 − 100 × (得分 − 28) / 54`，夹在 1 ~ 100
- **平均综测排名 = 6 次百分位的均值**，越小越好

**为什么重校准公式**：旧公式把百分位压在 34% ~ 89%（均值 66%），「≤5%」在 1000 局里出现 **0 次**，「≤40%」只有 2.3% —— 保研的两个门槛都不可达。重校准后实测：**≤5% 约 5%、≤40% 约 43%**，与目标占比匹配。

## 3. 硬门槛

| 结局 | 硬门槛 | 设计理由 | 实测通过率 |
| --- | --- | --- | --- |
| 保研外校 | `保研` 标签 ≥ 1 且 平均排名 ≤ **5%** | 保外校要求年级前列 | 11.3% |
| 保研本校 | `保研` 标签 ≥ 1 且 平均排名 ≤ **40%** | 保研的基本门槛 | 34.7% |
| 考研外校 | `图书馆` 标签 ≥ 2 | 考研需要长期自习 | 89.3% |
| 考研本校 | `图书馆` 标签 ≥ 2 | 同上 | 89.3% |
| 出国留学 | 家境 ≥ 7.1（即 **> 7**）且状态「语言成绩达标」 | 出国既需要经济支撑，也需要语言成绩 | 11.0% |
| 进入大厂 | `进大厂` 标签 ≥ 1 | 需要实习/技术经历 | 97.7% |
| 创业 | 家境 ≥ 6 | 创业需要启动资源 | 61.3% |
| 进入编制 | `学生组织` 标签 ≥ 1 | 体制内偏好学生干部经历 | 100% |
| 援建乡村 | `学生组织` 标签 ≥ 1 且 家境 < 6.1 | 与志愿经历挂钩，家境普通 | 41.3% |
| 待业 | 无门槛 | 保底结局，永远可选 | — |
| 延毕 | 智力 < 3.3 | 学业不达标才延毕 | 4.0% |

- 门槛全部写在 `data/endings.json` 里，代码不写死文案与阈值
- `need` 同时支持「属性下限」与「标签次数下限」：名字是四大属性就比属性值，否则比标签出现次数

## 4. 竞争与随机权重

满足门槛之后，不是「得分最高者胜」，而是**按竞争权重抽签**：

```
影响因子得分 = Σ √(属性值或标签次数) × 权重        ← 边际效用：数值越大，单点收益越小
竞争权重     = weight × 影响因子得分 × random(0.7, 1.3)   ← 随机权重
```

- **边际效用**：因子贡献取平方根，避免「某一项刷高就锁死结局」。例如智力从 9 涨到 16，贡献只从 3.0 涨到 4.0
- **随机权重**：每个结局每次判定乘一个 0.7 ~ 1.3 的随机系数，让同一份经历也有不同走向
- **竞争权重下限 0.01**：援建乡村的家境权重为负，可能算成负数，取 0.01 防止抽签参数非法
- `weight` 是**层级/类别权重**，按目标分布校准（2026-09-14 第 7 项 300 局复测后重新标定）：升学类里保研本校最高（6.2），保研外校 3.5、出国留学 2.2、考研本校 1.9、考研外校 0.7；就业类因门槛宽松而整体压低（进入大厂 0.26、进入编制 0.5、创业 0.62），援建乡村因门槛较窄（41.3%）取 2.4
- **入党加成**：转为正式党员的玩家带 `党员` 标签，`进入编制` 与 `援建乡村` 的影响因子各加 `党员 × 3` —— 入党后更容易走向体制内或援建

> **注（2026-09-14 · todo 第 7 项）**：上表与上文 §3 的「实测通过率」均已按 300 局全量测试（`test_7.md`）更新；权重按该测试重新标定（见 §4）。

### 已知偏差：待业永远打不到

- 待业是**纯兜底**：只有所有结局都不满足门槛时才命中
- 但就业类的门槛很宽（`进大厂` 97%、`进入编制` 100%），**没有任何一局能让全部门槛同时落空** → 待业 = 0%
- 这是「保持纯兜底」这一裁定的必然结果，差额按裁定并入了就业类（所以就业类普遍 +1 ~ +2.4）
- 若希望待业真的出现约 10%，需要二选一（**待人类定夺**）：
  1. 给待业一个真实门槛：如「平均排名 > 80% 且 无 `进大厂`/`竞赛`/`学生组织`/`保研` 经历」
  2. 收紧就业类门槛（如 `进入编制` 改为 `学生组织` ≥ 2、`进入大厂` 改为 `竞赛` ≥ 1），让门槛并集约覆盖 90%

## 7. 与旧判定的差异

| 项 | 旧判定 | 新判定 |
| --- | --- | --- |
| 选取方式 | 全部结局算分，取最高分 | 硬门槛过滤 + 加权抽签 |
| 因子影响 | 属性/标签线性加权 | 取平方根（边际效用）后加权 |
| 随机性 | 仅同分随机（实测 0.2%） | 每次判定乘 0.7 ~ 1.3 随机系数 |
| 经历的作用 | 无门槛，属性高就能命中 | 硬门槛决定「做过什么才能选」 |
| 院校 | 所有升学结局共用一个院校表 | 保研外校限「高于北理层级」8 所 |
| 可命中结局 | **2 种**（出国留学 56.6% / 保研外校 43.4%） | **10 种** |

## 8. 数据字段说明（`data/endings.json`）

| 字段 | 必填 | 含义 |
| --- | --- | --- |
| `name` | ✅ | 结局名（成就、存档用它匹配） |
| `text` | ✅ | 结局文案；`{school}` 会被替换成院校名 |
| `kind` | ✅ | `升学` / `就业` / `学业` / `兜底` |
| `weights` | ✅ | 影响因子（属性或标签 × 系数） |
| `weight` | 升学/就业 | 竞争权重（学业与兜底不需要） |
| `school` | 升学且含 `{school}` | `高位`（只在高位院校取档）/ `全部` |
| `need` | — | 硬门槛下限：属性值下限，或标签次数下限 |
| `need_max` | — | 硬门槛上限：属性值必须小于该值 |
| `flags_need` | — | 硬门槛：必须已具备的状态列表（如出国留学要求 `["语言成绩达标"]`） |
| `rank_max` | — | 平均综测百分位上限（%） |
