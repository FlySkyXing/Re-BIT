## 1. 等级与出现概率

| 等级 | 名称 | 颜色 | 出现概率 | 属性加成 |
| --- | --- | --- | --- | --- |
| 蓝 | 稀有 | `#3A76D0` | **75%** | +1 |
| 紫 | 史诗 | `#8052C6` | **20%** | +2 |
| 金 | 传说 | `#C69418` | **5%** | +4 |

- 开局随机抽 5 个，玩家最多选 2 个（可少选或不选，随时可以开始）
- 抽取时逐个掷等级（75 / 20 / 5），再从该等级未被抽走的天赋里随机取一个

## 4. 与事件相关的接口

天赋**不写逻辑**，只提供参数；筛选与生效统一由 `game/events.py` 处理。

| 字段 | 作用 | 生效位置 |
| --- | --- | --- |
| `boost` | `{事件标签: 倍率}`，带该标签的候选事件权重乘以倍率 | `pick_event` |
| `force` | `{round, stages, tags}`：回合号命中 `round`、或当前时段在 `stages` 中时，把候选**收窄**为带 `tags` 之一的事件；收窄后为空则退回正常池 | `apply_forces` |
| `shuyuan` | 非空则开局直接指定书院，进而影响书院限定事件的候选池 | `apply_talents` |
| `rewind` | 数值即百分比；每回合开始按此概率回溯到大一 9 月（回合号归 1、清空专业与已触发事件记录、**保留属性 / 天赋 / 书院**），**每局限一次** | `show_round` |

## 5. 数据结构（`data/talents.json`）

    {
      "tier_rates": { "蓝": 75, "紫": 20, "金": 5 },
      "talents": [
        {
          "name": "你就卷吧", "tier": "紫", "desc": "你的暑假、寒假必定留校",
          "effects": {},
          "shuyuan": "",
          "boost": {},
          "force": { "round": 0, "stages": ["寒假", "暑假"], "tags": ["竞赛", "实验", "图书馆"] },
          "rewind": 0
        }
      ]
    }

| 字段 | 含义 |
| --- | --- |
| `tier_rates` | 各等级出现概率（数值即权重） |
| `name` / `tier` / `desc` | 名称、等级、显示文本 |
| `effects` | 开局属性加成 |
| `shuyuan` | 指定书院；空字符串表示不指定 |
| `boost` | 标签加权；空对象表示不生效 |
| `force` | 强制事件规则；`round = 0` 与空 `stages` 表示不限，`tags` 为空表示不生效 |
| `rewind` | 回溯概率（%）；`0` 表示不生效 |

## 7. 事件标签约定（供 `boost` / `force` 使用）

| 标签 | 含义 |
| --- | --- |
| `竞赛` | 学科与科技竞赛 |
| `文体` | 文艺体育活动 |
| `实验` | 实验室 / 科研 |
| `图书馆` | 自习与借阅 |
| `学生组织` | 学生会、社团等组织 |
| `保研` | 保研相关 |
| `进大厂` / `进编制` | 就业方向相关 |

> 目前事件池是**占位文案**，标签先按上表打在占位事件上；正式文案阶段须保证这些标签仍有对应事件，否则 `boost` / `force` 会失效（不会报错，只是不生效）。
